# Product research notes

This project was informed by a current review of Flocus's public feature pages and help center. The target category includes:

- A customizable focus timer with Pomodoro, Countdown, Stopwatch, Animedoro, and 52/17-style modes.
- Aesthetic themes/backgrounds.
- Priority-based tasks with task ETAs.
- Layered soundscapes.
- Automatic focus stats and streaks with daily/weekly/monthly views.
- Curated music plus custom playlist connections.
- Extra workspace touches such as a clock/greeting, browser notifications, and picture-in-picture.

Sources reviewed on September 20, 2026:

- https://flocus.com/
- https://flocus.com/features/focus-timer
- https://flocus.com/features/themes
- https://flocus.com/features/stats
- https://help.flocus.com/en/articles/10247144-what-are-the-different-focus-timer-modes
- https://help.flocus.com/en/articles/10965919-setting-up-a-timer
- https://help.flocus.com/en/articles/10966495-customizing-your-dashboard

Visual direction was interpreted rather than copied: dark editorial dashboard, oversized time typography, restrained glass panels, lime-green accent, soft radial lighting, and a dense but calm utility layout. FocusForge uses its own CSS, generated ambient audio, icons, copy, and structure.
