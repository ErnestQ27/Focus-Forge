# FocusForge roadmap ideas

These are deliberately kept out of v1 so the core app remains free and easy to host.

- Cloud sync using a small user-owned backend.
- Import / export integrations for Todoist, Notion, or Google Tasks.
- Web Push instead of only browser notifications.
- Native Picture-in-Picture timer window where browser support is available.
- More visual themes and custom CSS variables.
- Session labels and project-level analytics.
- Optional local CSV export.
- Shared open-source theme / sound preset packs.
